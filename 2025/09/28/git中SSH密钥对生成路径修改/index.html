一、git中SSH密钥对生成路径修改

在安装git后配置ssh连接时，在生成密钥时会因自身系统名称为中文名字的原因，会出现提示找不到文件的报错，这时可以通过修改git生成密钥的地址进行解决

一、如果要修改默认的生成路径，具体操作如下：

  1. 按住windows + R，调出运行窗口，然后输入sysdm.cpl，点击确定；

  2. 在弹出的系统属性对话框中，点击【高级】选项卡；

  3. 接着点击右下角的【环境变量】；

（如果没有找到HOME配置，可以进行手动新增，里面的地址可以自行设置）

而我这里设置的是在D盘的etc文件下，然后我们去这到这个文件给他权限
