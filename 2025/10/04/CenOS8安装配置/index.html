一、服务器安装

安装 Infrastructure Server，右侧选 FTP + Compatibility Libraries 中文对应 基础设施服务器，FTP + 兼容性程序库
选择 Asia/Shanghai 时区

1.服务设置ip

2.检查服务器运行模式，查看系统是否带GUI界面

3.关闭selinux以及防火墙，并添加到rc.local开机启动中

4.检查每个服务器间是否能ping通，网络正常通讯

执行ifconfig查看网卡情况
检查/etc/sysconfig/network-scripts/下的网卡配置文件，是否是静态IP，且onBoot=yes（这里如果不是的话当服务器故障重启会连不上）

ping www.baidu.com 或者查看与内网是否通

Beyond_Compare4_30天试用到期的解决办法
在搜索栏中（win+R 键）输入 regedit ，打开注册表 然后找到这个地址删除项目：\HKEY_CURRENT_USER\Software\ScooterSoftware\Beyond Compare 4\CacheId 的cacheid 右击删除掉就可以 然后重新打开下beyond compare

创建虚拟IP
复制现有 ens32 的配置文件，创建虚拟 IP 的配置（以 ens32:0 为别名）： 1sudo cp /etc/sysconfig/network-scripts/ifcfg-ens32 /etc/sysconfig/network-scripts/ifcfg-ens32:0 编辑虚拟 IP 的配置文件： 1sudo vim /etc/sysconfig/network-scripts/ifcfg-ens32:0 修改以下内容（其他参数保持与 ifcfg-ens32 一致）： 12345678910111213141516171819202122232425NAME=ens32:0 # 名称与文件名对应DEVICE=ens32:0 # 设备名与文件名对应IPADDR=192.168.1.101 # 虚拟 IP 地址# 注释或删除 UUID（避免冲突）# UUID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx如下：TYPE=EthernetPROXY_METHOD=noneBROWSER_ONLY=noBOO...
